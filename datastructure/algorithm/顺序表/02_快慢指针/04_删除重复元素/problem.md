## 问题
# 顺序表删除重复元素

## 题目描述

给定一个非降序排列的顺序表 `L`,删除其中重复的元素,每个值只保留一个,其余元素保持原有的相对顺序.

要求:

- 不允许使用额外的数组存储元素.
- 空间复杂度为 \(O(1)\).

## 输入格式

- 第一行输入一个整数 `n`,表示顺序表的长度.
- 第二行输入 `n` 个整数,表示顺序表中的元素,元素之间用空格分隔,且保证非降序排列.

## 输出格式

输出去重后的顺序表,元素之间用一个空格分隔.

## 数据范围

- \(1 \leq n \leq 10^6\)
- \(-10^9 \leq L_i \leq 10^9\)
- 保证顺序表按非降序排列,即 \(L_1 \leq L_2 \leq \cdots \leq L_n\)

## 输入输出示例

### 示例 1

输入:

```text
6
-5 -5 -3 0 0 7
```

输出:

```text
-5 -3 0 7
```

### 示例 2

输入:

```text
12
-1000000000 -1000000000 -1 -1 -1 0 0 999999999 999999999 1000000000 1000000000 1000000000
```

输出:

```text
-1000000000 -1 0 999999999 1000000000
```

## 要求

- 时间复杂度:\(O(n)\)
- 辅助空间复杂度:\(O(1)\)
