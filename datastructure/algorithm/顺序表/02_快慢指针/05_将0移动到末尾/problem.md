## 问题
# 顺序表将0移动到末尾

## 题目描述

给定一个顺序表 `L`,将其中的所有 `0` 移动到末尾,非零元素的相对顺序保持不变.

要求:

- 不允许使用额外的数组存储元素.
- 空间复杂度为 \(O(1)\).

## 输入格式

- 第一行输入一个整数 `n`,表示顺序表的长度.
- 第二行输入 `n` 个整数,表示顺序表中的元素,元素之间用空格分隔.

## 输出格式

输出移动后的顺序表,元素之间用一个空格分隔.

## 数据范围

- \(1 \leq n \leq 10^6\)
- \(-10^9 \leq L_i \leq 10^9\)

## 输入输出示例

### 示例 1

输入:

```text
8
0 1 0 3 12 0 -5 0
```

输出:

```text
1 3 12 -5 0 0 0 0
```

### 示例 2

输入:

```text
10
7 0 -3 0 0 21 -3 0 8 0
```

输出:

```text
7 -3 21 -3 8 0 0 0 0 0
```

## 要求

- 时间复杂度:\(O(n)\)
- 辅助空间复杂度:\(O(1)\)
