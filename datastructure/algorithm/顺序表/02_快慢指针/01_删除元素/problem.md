## 问题
# 顺序表删除元素

## 题目描述

给定一个顺序表 `L` 和一个整数 `x`,删除顺序表中所有值等于 `x` 的元素,其余元素保持原有的相对顺序.

要求:

- 不允许使用额外的数组存储元素.
- 空间复杂度为 \(O(1)\).

## 输入格式

- 第一行输入两个整数 `n` 和 `x`,分别表示顺序表的长度和要删除的元素值,用空格分隔.
- 第二行输入 `n` 个整数,表示顺序表中的元素,元素之间用空格分隔.

## 输出格式

输出删除后的顺序表,元素之间用一个空格分隔.

## 数据范围

- \(1 \leq n \leq 10^5\)
- \(-10^9 \leq x, L_i \leq 10^9\)
- 保证删除后顺序表非空

## 输入输出示例

### 示例 1

输入:

```text
5 3
1 2 3 4 5
```

输出:

```text
1 2 4 5
```

### 示例 2

输入:

```text
10 0
0 -1 0 -1 2 2 -3 -3 0 4
```

输出:

```text
-1 -1 2 2 -3 -3 4
```

## 要求

- 时间复杂度:\(O(n)\)
- 辅助空间复杂度:\(O(1)\)
