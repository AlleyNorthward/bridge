## 问题
# 顺序表哈希去重

## 题目描述

给定一个元素顺序任意的顺序表 `L`,删除其中重复的元素,每个值只保留第一次出现的那个,其余元素保持原有的相对顺序.

要求使用哈希表实现,平均时间复杂度为 \(O(n)\).

## 输入格式

- 第一行输入一个整数 `n`,表示顺序表的长度.
- 第二行输入 `n` 个整数,表示顺序表中的元素,元素之间用空格分隔.

## 输出格式

输出去重后的顺序表,元素之间用一个空格分隔.

## 数据范围

- \(1 \leq n \leq 10^6\)
- \(-10^9 \leq L_i \leq 10^9\)

## 输入输出示例

### 示例 1

输入:

```text
7
4 2 4 1 2 3 1
```

输出:

```text
4 2 1 3
```

### 示例 2

输入:

```text
8
-5 0 -5 7 0 7 -5 0
```

输出:

```text
-5 0 7
```

## 要求

- 时间复杂度:\(O(n)\)(平均)
- 辅助空间复杂度:\(O(n)\)
