## 问题
# 顺序表每个元素最多保留两次

## 题目描述

给定一个元素顺序任意的顺序表 `L`,对每个不同的值,最多保留它的前两次出现,删除其余出现,保留下来的元素保持原有的相对顺序.

要求使用哈希表记录每个值已经出现的次数,平均时间复杂度为 \(O(n)\).

## 输入格式

- 第一行输入一个整数 `n`,表示顺序表的长度.
- 第二行输入 `n` 个整数,表示顺序表中的元素,元素之间用空格分隔.

## 输出格式

输出保留下来的顺序表,元素之间用一个空格分隔.

## 数据范围

- \(1 \leq n \leq 10^6\)
- \(-10^9 \leq L_i \leq 10^9\)

## 输入输出示例

### 示例 1

输入:

```text
8
1 1 1 2 2 2 2 3
```

输出:

```text
1 1 2 2 3
```

### 示例 2

输入:

```text
9
-5 -5 -5 0 7 0 7 7 -5
```

输出:

```text
-5 -5 0 7 0 7
```

## 要求

- 时间复杂度:\(O(n)\)(平均)
- 辅助空间复杂度:\(O(n)\)
