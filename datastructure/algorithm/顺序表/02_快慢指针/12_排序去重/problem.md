## 问题
# 顺序表排序去重

## 题目描述

给定一个顺序表 `L`,删除其中重复的元素,并将剩余元素按从小到大的顺序排列,每个值只输出一次.

要求:

- 不允许使用额外的数组存储元素.
- 空间复杂度为 \(O(1)\).

## 输入格式

- 第一行输入一个整数 `n`,表示顺序表的长度.
- 第二行输入 `n` 个整数,表示顺序表中的元素,元素之间用空格分隔.

## 输出格式

输出去重并排好序的顺序表,元素之间用一个空格分隔.

## 数据范围

- \(1 \leq n \leq 10^6\)
- \(-10^9 \leq L_i \leq 10^9\)

## 输入输出示例

### 示例 1

输入:

```text
7
4 2 4 1 2 3 1
```

输出:

```text
1 2 3 4
```

### 示例 2

输入:

```text
8
-5 0 -5 7 0 7 -5 0
```

输出:

```text
-5 0 7
```

## 要求

- 时间复杂度:\(O(n \log n)\)
- 辅助空间复杂度:\(O(1)\)
