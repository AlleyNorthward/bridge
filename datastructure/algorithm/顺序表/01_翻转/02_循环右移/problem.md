## 问题
# 顺序表循环右移

## 题目描述

给定一个顺序表 `L` 和一个非负整数 `k`,将顺序表中的所有元素循环右移 `k` 个位置.循环右移指每个元素向后移动 `k` 个位置,超出末尾的元素回到开头;`k` 可以大于 `n`,此时等价于右移 \(k \bmod n\) 个位置.

要求:

- 不允许使用额外的数组存储元素.
- 空间复杂度为 \(O(1)\).

## 输入格式

- 第一行输入两个整数 `n` 和 `k`,分别表示顺序表的长度和循环右移的位置数,用空格分隔.
- 第二行输入 `n` 个整数,表示顺序表中的元素,元素之间用空格分隔.

## 输出格式

输出循环右移后的顺序表,元素之间用一个空格分隔.

## 数据范围

- \(1 \leq n \leq 10^6\)
- \(0 \leq k \leq 10^9\)
- \(-10^9 \leq L_i \leq 10^9\)

## 输入输出示例

### 示例 1

输入:

```text
5 2
1 2 3 4 5
```

输出:

```text
4 5 1 2 3
```

### 示例 2

输入:

```text
10 3
0 -1 0 -1 2 2 -3 -3 0 4
```

输出:

```text
-3 0 4 0 -1 0 -1 2 2 -3
```

## 要求

- 时间复杂度:\(O(n)\)
- 辅助空间复杂度:\(O(1)\)
