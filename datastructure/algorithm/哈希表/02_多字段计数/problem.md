## 问题
# 统计每个值的出现次数与总和

## 题目描述

给定一个顺序表 `L`,统计每个不同值的出现次数,以及该值所有出现元素之和.

要求使用哈希表实现,平均时间复杂度为 \(O(n)\).

## 输入格式

- 第一行输入一个整数 `n`,表示顺序表的长度.
- 第二行输入 `n` 个整数,表示顺序表中的元素,元素之间用空格分隔.

## 输出格式

按每个值第一次出现的顺序,每行输出三个整数:该值、出现次数、所有出现元素之和,用空格分隔.

## 数据范围

- \(1 \leq n \leq 10^6\)
- \(-10^9 \leq L_i \leq 10^9\)
- 保证每个值的总和在 64 位有符号整数范围内

## 输入输出示例

### 示例 1

输入:

```text
8
3 1 3 2 1 4 2 5
```

输出:

```text
3 2 6
1 2 2
2 2 4
4 1 4
5 1 5
```

### 示例 2

输入:

```text
9
-5 0 -5 7 0 7 -5 0 3
```

输出:

```text
-5 3 -15
0 3 0
7 2 14
3 1 3
```

## 要求

- 时间复杂度:\(O(n)\)(平均)
- 辅助空间复杂度:\(O(n)\)
