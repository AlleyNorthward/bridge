## qustion
- 给定一个升序顺序表 L 和目标值 target.
- 请找到第一个 严格大于 target 的元素下标.

```c
void solve(vector *vec) {
  int target = 5;
  int start = 0, end = vec->size-1;
  int pos = -1;
  while(start <= end){
    int mid = start + (end - start) / 2;
    if(vec->data[mid] <= target){
      start = mid + 1;
    } else {
      pos = mid;
      end = mid - 1;
    }
  }

  printf("pos: %d, num: %d\n", pos, vec->data[pos]);
}
```
