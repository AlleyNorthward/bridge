## 分析
- 对于这些二分类型的, 实际上, 也是比较简单的
- 首先, 圈定三个范围, 也就是vec->data[mid]跟target的关系
  - 也就是[mid] < target, [mid] > target, [mid]=target
- 其次, 就是记录位置, 也就是变量pos
- 最后是位置压缩
- 关键就是记录与压缩
- 三个范围内, 何时都能压缩, 三个范围内, 何时都能记录

- 对于基础问题, 找target, 不等时压缩, 相等时记录pos, 初始pos=-1, 若最后仍为-1, 表示未找到
- 对于左边界二分(target第一次出现), 此时, 不等时压缩, 相等时也压缩(左压缩, end=mid-1), 并且记录位置
- 右边界二分也是(target最后出现), 此时不等时压缩, 相等时压缩(右压缩, start=mid+1), 记录pos
- 下边界查找呢, 实际上, 就是左边界二分基础上, 不等时(vec->data[mid]>target), 记录
- 上边界查找(第一个严格大于target的元素下标), 也是一个道理的

- 例如数据, `6888889`, target=8
- 基础就是随意找个8, 证明有就行
- 左边界二分, 就是找第一个8
- 右边界二分, 找最后一个8
- 下界查找, 就是找第一个8, 如果target改为7, 则是找6
- 上界查找, 找第一个严格大于8的, 也就是9

## 组块
- 首先, 先写出来一般的, 也就是找中间
```c
void solve(vector* vec){
  int start = 0, end = vec->size-1;
  int target = 3;
  int pos = -1;

  while(start <= end){
    int mid = start + (end - start) / 2;
    if(vec->data[mid] < target){
      start = mid + 1;
    } else if (vec->data[mid] > target){
      end = mid - 1;
    } else {
      pos = mid;
    }
  }

  printf("pos: %d\n", pos);
}
```

  int target = 3;

## 说明
- 第一个大于或等于的, 存在找最左侧, 不存在, 找第一个大于的
- 第一个小于或等于的, 存在找最右侧, 不存在找第一个小于的
- 实际上就是语义混乱
- 会找target, 第一个, 最后一个, 第一个小于, 第一个大于, 我觉得就够了
- 关于复合, 实际上就是对pos位置的分析与判断了
