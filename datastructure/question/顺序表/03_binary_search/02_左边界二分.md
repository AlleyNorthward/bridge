## qustion
- 给定一个升序顺序表 L,其中可能存在重复元素.
- 请设计一个算法,找到目标值 target 第一次出现的位置.

```c
void solve(vector *vec) {
  int target = 2;
  int start = 0, end = vec->size - 1;
  int pos = -1;
  while(start<=end){
    int mid = start + (end - start) / 2;
    if(vec->data[mid] < target){
      start = mid+1;
    } else if(vec->data[mid] > target){
      end = mid-1;
    } else {
      pos = mid;
      end = mid-1;
    }
  }

  printf("pos: %d\n", pos);

}
```
