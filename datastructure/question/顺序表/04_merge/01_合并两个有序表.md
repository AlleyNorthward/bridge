## question
- 给定两个已经按照升序排列的顺序表 A 和 B.
- 请设计一个算法,将它们合并成一个新的升序顺序表 C.

```c
void solve(vector* vec1, vector* vec2, vector* vec3){
  int p1 = 0, p2 = 0, p3 = 0;

  while(p1 < vec1->size && p2 < vec2->size){
    if(vec1->data[p1] <= vec2->data[p2]){
      vec3->data[p3++] = vec1->data[p1++];
    } else {
      vec3->data[p3++] = vec2->data[p2++];
    }
  }

  while(p1 < vec1->size){
    vec3->data[p3++] = vec1->data[p1++];
  }

  while(p2 < vec2->size){
    vec3->data[p3++] = vec2->data[p2++];
  }

  vec3->size = p3;
}
```
