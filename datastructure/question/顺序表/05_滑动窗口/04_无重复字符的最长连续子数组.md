## question
- 给定一个整数数组,请找出其中不包含重复元素的最长连续子数组,返回它的长度.
- arr = {1, 2, 3, 2, 4, 5, 3};
- [1, 2, 3]
- [2, 4, 5, 3]
- 答案 4

## 答案
```c
int solve(vector *vec) {
    int visited[101] = {0};

    int slow = 0;
    int max = 0;

    for (int fast = 0; fast < vec->size; ++fast) {

        int num = vec->data[fast];

        while (visited[num]) {
            visited[vec->data[slow]] = 0;
            ++slow;
        }

        visited[num] = 1;

        int len = fast - slow + 1;

        if (len > max)
            max = len;
    }

    return max;
}
```
