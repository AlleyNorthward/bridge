## question
- 给定一个只包含正整数的数组 arr,以及一个目标值 target.
- 请找出数组中满足以下条件的连续子数组:
- sum \ge target
- 返回满足条件的子数组的最小长度
- arr = {2, 3, 1, 2, 4, 3}; target = 7;
- [2, 3, 1, 2]    sum = 8   length = 4
- [3, 1, 2, 4]    sum = 10  length = 4
- [1, 2, 4]       sum = 7   length = 3
- [4, 3]          sum = 7   length = 2
- 答案为2

## 答案
```c
void solve(vector *vec) {
  int target = 2;
  int slow = 0, fast = 0;
  int sum = 0;
  int min = INT_MAX;

  for(;fast < vec->size; ++fast){
    sum += vec->data[fast];
    while(sum >= target){
      int len = fast - slow;
      min = sum < min ? sum : min;
      sum -= vec->data[slow++];
    }
  }

  printf("%d\n", min);
}
```
