## question
- 给定一个整数数组 arr 和一个正整数 k.
- 请你设计一个算法,找出数组中所有长度为 k 的连续子数组,并返回其中最大的元素和.

## 答案
```c
void solve(vector *vec) {
  int k = 3;
  int sum=0;
  
  for(int i = 0; i < k; ++i){
    sum += vec->data[i];
  }

  int max = sum;

  for(int i = k; i < vec->size; ++i){
    sum -= vec->data[i-k];
    sum += vec->data[i];

    max = sum > max ? sum : max;
  }

  printf("%d\n", max);
}
```
