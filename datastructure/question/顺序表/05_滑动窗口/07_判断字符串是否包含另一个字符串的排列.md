## question
- 给定两个字符串 s1 和 s2,判断 s2 是否包含 s1 的某种排列.
- 
- 如果包含,返回 1,否则返回 0.
- 
- 示例:
- s1 = "ab";
- s2 = "eidbaooo";
- 
- 
- 答案:
- 1
- 
- 
- 因为 s2 中存在子串 "ba",它是 "ab" 的一种排列.
- 
- 再看一个：
- s1 = "ab";
- s2 = "eidboaoo";
- 
- 
- 答案:
- 0
- 
- 
- 因为不存在同时包含一个 a 和一个 b 的长度为 2 的连续子串.

## 答案
```c
#include <string.h>

int containsPermutation(const char *s1, const char *s2) {
    int m = strlen(s1);
    int n = strlen(s2);

    if (m > n)
        return 0;

    int need[26] = {0};
    int window[26] = {0};

    for (int i = 0; i < m; ++i) {
        ++need[s1[i] - 'a'];
    }

    for (int i = 0; i < m; ++i) {
        ++window[s2[i] - 'a'];
    }

    if (memcmp(need, window, sizeof(need)) == 0)
        return 1;

    for (int fast = m; fast < n; ++fast) {

        --window[s2[fast - m] - 'a'];

        ++window[s2[fast] - 'a'];

        if (memcmp(need, window, sizeof(need)) == 0)
            return 1;
    }

    return 0;
}
```
