## question
- 给定一个整数数组 arr,以及两个目标元素 a 和 b.
- 
- 请找出一个同时包含 a 和 b 的最短连续子数组,返回它的长度.
- 
- 示例:
- arr = {1, 3, 2, 5, 3, 4, 2, 1};
- a = 3;
- b = 4;
- 
- 
- 其中:
- [3, 2, 5, 3, 4]  length = 5
- [5, 3, 4]        length = 3
- 
- 
- 答案:3

## 答案
```c
int slove(vector *vec, int a, int b) {
    int posA = -1;
    int posB = -1;
    int min = INT_MAX;

    for (int i = 0; i < vec->size; ++i) {

        if (vec->data[i] == a)
            posA = i;

        if (vec->data[i] == b)
            posB = i;

        if (posA != -1 && posB != -1) {
            int len = abs(posA - posB) + 1;

            if (len < min)
                min = len;
        }
    }

    return min == INT_MAX ? 0 : min;
}
```
