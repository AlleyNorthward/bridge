## question
- 给定一个整数数组 arr 和一个整数 k.
- 
- 请找出一个连续子数组,使得其中不同元素的种类数量不超过 k,返回最长子数组的长度.
- 
- 示例:
- arr = {1, 2, 1, 2, 3, 2, 2};
- k = 2;
- 
- 
- 观察:
- [1, 2, 1, 2]       长度 = 4
- [2, 1, 2, 3]       不满足，包含 3 种元素
- [1, 2, 3]          不满足
- [2, 3, 2, 2]       长度 = 4
- 
- 
- 答案:4

## 答案
```c
int solve(vector *vec, int k) {
    int freq[101] = {0};

    int slow = 0;
    int kinds = 0;
    int max = 0;

    for (int fast = 0; fast < vec->size; ++fast) {

        int num = vec->data[fast];

        if (freq[num] == 0)
            ++kinds;

        ++freq[num];

        while (kinds > k) {
            int left = vec->data[slow++];

            --freq[left];

            if (freq[left] == 0)
                --kinds;
        }

        int len = fast - slow + 1;

        if (len > max)
            max = len;
    }

    return max;
}
```
