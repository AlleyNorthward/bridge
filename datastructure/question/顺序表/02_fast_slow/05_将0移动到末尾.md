## question
- 给定顺序表,将所有的 `0` 移动到末尾,非零元素的相对顺序保持不变.

## 答案
```c
void solve(vector *vec) {
  int fast = 0, slow = 0;
  for(;fast < vec->size; ++fast){
    if(vec->data[fast] != 0){
      int tmp = vec->data[slow];
      vec->data[slow++] = vec->data[fast];
      vec->data[fast] = tmp;
    }
  }
}
```

## 分析
- 这里就是换了操作, 非法的放到后面, 合法的往前放
- 判断范围就是是否为0
- 操作上面说了
- 长度不变
