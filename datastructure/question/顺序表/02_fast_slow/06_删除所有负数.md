## question
- 给定一个顺序表,将其中所有负数删除,其他元素保持原有相对顺序.

## 答案
```c
void solve(vector *vec) {
  int fast = 0, slow = 0;
  for(; fast < vec->size; ++fast){
    if(vec->data[fast]>=0){
      vec->data[slow++] =vec->data[fast];
    }
  }

  vec->size = slow;
}
```

## 分析
- 判断是否是负数
- 是负数, fast++, 不是负数, slow++, fast++
- 长度为slow
