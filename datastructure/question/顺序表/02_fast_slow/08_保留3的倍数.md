## question
- 删除顺序表中所有不能被 3 整除的元素,保留其他元素的相对顺序.

## 答案
```c
void solve(vector *vec) {
  int fast = 0, slow = 0;
  for(;fast<vec->size;++fast){
    if(vec->data[fast]%3==0){
      vec->data[slow++] =vec->data[fast];
    }
  }
  vec->size = slow;
}
```

## 分析
- 条件是能被3整除, fast++, slow++, 不能被3整除, fast++
- 操作, 覆盖
- 长度为[0,slow), 也就是slow
