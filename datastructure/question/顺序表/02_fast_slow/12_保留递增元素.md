## question
- 给定一个无序数组,只保留那些严格大于它前面所有元素的元素.

## 答案
```c
void solve(vector *vec) {
  int fast = 1, slow = 0;
  for (; fast < vec->size; ++fast) {
    if (vec->data[fast] > vec->data[slow]) {
      vec->data[++slow] = vec->data[fast];
    }
  }

  vec->size = slow + 1;
}
```

## 分析
- slow维护的是严格递增的
- 那么, 就是判断slow跟fast值, 如果fast>slow, fast++,slow++
- 但是fast初始为1, slow初始为0
- 操作是, slow++, 覆盖
- 长度为slow+1 这里没有分析, 因为slow先++, 一般就是维护[0,slow]
