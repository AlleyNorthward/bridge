## question
- 删除所有满足下面条件的元素
- `arr[i] < arr[i-1] && arr[i] < arr[i+1]`
- 输入:[5, 3, 6, 2, 7, 4, 8]
- 输出:[5, 6, 7, 8]

## 答案
```c
void solve(vector *vec) {
  int fast = 1, slow = 0;
  for (; fast < vec->size - 1; ++fast) {
    if (!(vec->data[fast] < vec->data[fast - 1] &&
          vec->data[fast] < vec->data[fast + 1])) {
      vec->data[++slow] = vec->data[fast];
    }
  }

  vec->data[++slow] = vec->data[vec->size-1];
  vec->size = slow + 1;
}
```

## 分析
- 范围问题, fast初始=1, 末尾=size-1-1, 也就是指向倒数第二个
- 执行结束后, 最后一个元素要添加到slow中
- slow维护长度为[0,slow]
- 判断是, 注意, 是要删除, 所以, 满足条件, fast++, 不满足, fast++,slow++
- slow++后, 再覆盖
