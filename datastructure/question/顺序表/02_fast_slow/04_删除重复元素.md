## question
- 给定一个已经有序的顺序表,删除重复元素,只保留一个.

## 答案
```c
void solve(vector *vec) {
  int fast = 1, slow = 0;
  for(;fast<vec->size;++fast){
    if(vec->data[fast] != vec->data[slow]){
      vec->data[++slow] = vec->data[fast];
    }
  }

  vec->size = slow+1;
}
```

## 分析
- 这个题, 跟前面三个不一样
- 条件就是数组slow值跟fast值是否相等
- 操作也是覆盖, 但是是延迟覆盖, 也就是先+1, 后覆盖
- 最终维护长度是[0,slow], 所以数组长度改为slow+1
