## question
- 给定一个顺序表,将所有偶数放到前面,所有奇数放到后面.

## 答案
```c
void solve(vector *vec) {
  int fast = 0, slow = 0;
  for(;fast<vec->size;++fast){
    if(vec->data[fast] % 2 == 0){
      int tmp = vec->data[slow];
      vec->data[slow++] = vec->data[fast];
      vec->data[fast] = tmp;
    }
  }
}
```

## 分析
- 判断, 是偶数, slow++, fast++, 不是偶数, fast++
- 操作是交换
- 长度是原长度

- 通过这个题来看, 分区, 就是用交换, 不分区, 则是覆盖, 一种筛选过滤的方法
