## question
- 给定一个任意顺序的顺序表,只保留每段连续相同元素中的一个.

## 答案
```c
void solve(vector *vec) {
  int fast = 1, slow = 0;
  for(;fast<vec->size; ++fast){
    if(vec->data[slow]!=vec->data[fast]){
      vec->data[++slow] = vec->data[fast];
    }
  }

  vec->size = slow+1;
}
```

## 分析
- 这跟第四个是类似的
- fast初始为1, slow初始为0
- 判断是fast值跟slow值是否相等, 相等, fast++, 不等, 覆盖, slow++,fast++
- 长度为[0,slow], 也就是slow+1
- 先++后覆盖
