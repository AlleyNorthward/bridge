## question
- 删除值在区间 [s,t] 内的元素

## 答案
```c
void solve(vector *vec) {
  int s = -7, t = 8;
  int fast = 0, slow = 0;
  for(;fast < vec->size; ++fast){
    if(!(vec->data[fast]>=s && vec->data[fast] <= t)){
      vec->data[slow++] = vec->data[fast];
    }
  }

  vec->size = slow;
}
```

## 分析
- 条件为在区间内, 不在区间内
- 操作为覆盖
- slow维度[0,slow), 长度为slow
