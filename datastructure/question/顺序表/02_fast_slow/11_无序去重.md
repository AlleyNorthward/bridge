## 答案
```c
int isinslow(vector *vec, int slow, int num) {
  for (int i = 0; i < slow; ++i) {
    if (vec->data[i] == num) {
      return 1;
    }
  }
  return 0;
}

void solve(vector *vec) {
  int fast = 0, slow = 0;
  for (; fast < vec->size; ++fast) {
    if (!isinslow(vec, slow, vec->data[fast])) {
      vec->data[slow++] = vec->data[fast];
    }
  }

  vec->size = slow;
}
```

## 分析
- 维护区间是[0,slow)
- 在区间内, fast++, 不在区间, slow++, fast++
- 上述是O(n^2)算法时间复杂度哈
- 而排序再去重, 时间复杂度可以O(nlogn)
