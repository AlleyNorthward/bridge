## question
- 给定顺序表 `L`,删除所有值为 `x` 的元素.

## 答案
```c
void solve(vector *vec) {
  int x = 5;
  int fast = 0, slow = 0;
  for (; fast < vec->size; ++fast) {
    if(vec->data[fast] != x){
      vec->data[slow++] = vec->data[fast];
    }
  }

  vec->size = slow;
}
```

## 分析
- 条件为等于x, 不等于x这两种情况
- 具体操作为覆盖, 不是交换
- `slow`维护[0,slow), 最终长度为slow
