## question
给定一个值 `x`,将顺序表划分为三部分:
- 小于 `x` 的元素;
- 等于 `x` 的元素;
- 大于 `x` 的元素.

## 答案
```c
void solve(vector *vec) {
  int x = 5;
  int fast = 0, slow = 0, size = vec->size;

  while(fast < size){
    if(vec->data[fast] < x){
      int tmp = vec->data[slow];
      vec->data[slow++] = vec->data[fast];
      vec->data[fast] = tmp;
      ++fast;
    } else if (vec->data[fast] == x){
      ++fast;
    } else{
      int tmp = vec->data[fast];
      vec->data[fast] = vec->data[size-1];
      vec->data[size-1] = tmp;

      --size;
    }
  }
}
```

## 分析
- 这个跟之前的都不一样
- 对于fast值, 之前就是两种可能, 要么符合条件, 要么不符合条件
- 而这里, 给出了三种情况, 小于, 等于, 大于, 这也是难点所在
- 小于x时, slow++, fast++, swap
- 等于x时, fast++
- 大于x时, 将数组尾巴跟fast swap, 长度--, 注意fast不变哈
- 这里其实还是跟着之前答案来的哈, 但是影响也不大
