## question
- 给定顺序表 `L` 和整数 `x`,删除所有不等于 `x` 的元素.

## 答案
```c
void solve(vector *vec) {
  int x = 5;

  int fast = 0, slow = 0;
  for(;fast < vec->size; ++fast){
    if(vec->data[fast] == x){
      vec->data[slow++] = vec->data[fast];
    }
  }

  vec->size = slow;
}
```

- 跟前面两个, 是一个情况
- 先找范围, 再分析操作, 后判断长度
