## question
-- 给定顺序表 L 和整数 k,将顺序表中的所有元素循环左移 k 个位置.

## 答案
```c
void reverse(vector* vec, int start, int end){
  while(start < end){
    int tmp = vec->data[start];
    vec->data[start] = vec->data[end];
    vec->data[end] = tmp;

    ++start;
    --end;
  }
}

void solve(vector *vec) {
  int k = 3;
  reverse(vec, 0, vec->size-1);
  reverse(vec, 0, vec->size-k-1);
  reverse(vec, vec->size-k, vec->size-1);
}
```
